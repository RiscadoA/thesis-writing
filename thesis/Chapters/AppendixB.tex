\chapter{IR Instruction Reference}
\label{chapter:appendixIR}

This appendix contains full list of \ac{IR} instructions used in this thesis, along with a brief description of each instruction and its arguments. \texttt{<dloc>} refers to a data location, \texttt{<cloc>} refers to a code location, \texttt{<expr>} refers to an expression and \texttt{<slots>} refers to a slot tree.
