\noindent Session-typed programming languages based on linear logic, such as CLASS, enforce memory safety and deadlock-freedom by construction. The Linear Session Abstract Machine (SAM) was introduced to provide a formal model for sequentially executing the processes of session-typed languages, allowing for orders of magnitude better runtime performance than existing interpreters which spawn threads for each concurrent process. However, the SAM remains an interpreter, which introduces a performance overhead compared to a compiled language, even though the language is very strongly statically typed. This project introduces a compilation scheme for CLASS, which translates the high-level session-typed language into an efficient low-level imperative language (C) while maintaining all of the safety and liveness guarantees of the source language. During this project, a prototype has been developed which covers all of the language features and which implements multiple optimization techniques. It is already possible to compile and run programs written in CLASS, achieving performance multiple orders of magnitude better than the SAM interpreter.
