This chapter describes the various optimizations implemented during this project. The first section goes over the transformations made to the \ac{IR} generation phase to produce more efficient \ac{IR} code. The second section describes optimizations specific to the C code generation phase. The third section introduces a new compilation phase which applies a series of transformations to the generated \ac{IR} code before passing it to the C code generation phase. Finally, the last section discusses some possible future optimizations which could be implemented in the compiler.
