Strongly typed languages allow programmers to guarantee multiple properties about their code, such as memory safety and deadlock freedom. Additionally, the type system can be used to provide more information about the behavior of the code to the compiler, opening up new optimisation paths. One example of this is the Rust programming language, which, through an affine type system, is able to guarantee memory safety by enforcing the ownership of resources, preventing data races and dangling pointers. However, Rust still does not guarantee that concurrent programs are deadlock free, as it does not have a type system that enforces communication protocols.

Session types \cite{Honda:1993,Honda:1998} have been used to enforce correctness in communication protocols, namely in languages based on process calculus, which model concurrent systems \cite{Milner:1980,Milner:1992:1,Milner:1992:2}. By coupling session types with linear logic \cite{Girard:1987,Caires:2010}, it has been possible to additionally guarantee deadlock freedom. CLASS \cite{Rocha:2022}, is an example of a session-typed language, built on top of the correspondence between session types and linear logic, that provides these guarantees. The original CLASS interpreter implemented by Rocha et al. \cite{Rocha:2021:artifact} served as a proof of concept for the language, and thus it was not optimized for performance, and thus, it was not suitable for real-world applications.

The Linear Session Abstract Machine (SAM) \cite{Caires:2024} is an abstract machine that allows for the sequential execution of session-typed languages, such as CLASS, through the use of buffered communication channels. Caires et al. expanded the existing CLASS interpreter with this new scheme \cite{Caires:2024:artifact}. This permitted a great increase in performance, as the overhead of spawning threads is very high in modern systems, and thus it is not feasible to spawn threads for every parallel process in a session-typed program, as most threads end up executing few instructions and spend most time waiting for communication. However, the SAM still does not make use of the properties of the source language to generate efficient machine code, as it is a high-level abstract machine.

\subsection{Work Objectives}

This project aims to provide a compilation scheme which translates the session-typed language CLASS into a low-level imperative language, such as C, while maintaining all of safety and liveness guarantees of CLASS. This approach will allow the execution of CLASS programs possibly in orders of magnitude more efficient manner than the SAM interpreter, as the compiler will have extensive knowledge of the compiled programs. The SAM interpreter, on which the compiler is based, currently has no support for the affine sessions, reference cells and shared state features of CLASS. Instead, it covers only the pure fragment of the language. In this work, we aim to support all of the features of CLASS in the compiled programs, including the aforementioned ones.

The base CLASS language will also be extended with interoperation features with C, allowing programs to interact with the C standard library and other C programs. This will allow for the creation of more complex programs, which will be helpful to measure the real-world performance of the compiled programs. With this thesis, we also aim to use the properties guaranteed by the source language to optimize the target code in a way that is not possible for commonly used programming languages. We will compare the performance of the compiled programs with the original CLASS interpreter, the SAM interpreter, and with equivalent programs written in other languages, such as Rust and C.
