\section{Evaluation}

The proposed solution will be tested extensively through a bench of incremental unit tests written in the CLASS language. This is already underway, with multiple existing tests for each of the implemented features.

The solution will also be evaluated by comparing the performance of the compiled code with the original CLASS interpreter and with the SAM interpreter, on multiple examples of the CLASS language. The impact on the performance gained by any implemented optimizations will also be measured.

Additionally, using the CLASS and C interop features introduced by this project, it will be possible to write CLASS programs that receive data and output data from and into the standard input and output pipes. This will allow measuring the performance of CLASS programs which perform computation on input, such as computing the Fibonacci sequence, the factorial of a number, or sorting a list. The runtime and memory usage of these programs will then be compared with equivalent programs written in C, Haskell (GHC), and possibly other languages.
